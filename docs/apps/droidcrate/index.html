02

Built for the bench

Look first. Then act.

The useful work is unglamorous: identify the phone, name the source, gate the risky step, and keep a record. DroidCrate does that part.

  1. 01

    Know what's on the other end

    Windows Plug and Play records are read locally. DroidCrate names the USB mode, the likely device family, and the safest next step.

    USB
  2. 02

    Official pages only

    Every entry says who publishes the tool. Vendor software opens on the vendor's own page — no mirrors, no repacks, and no bundled firmware.

    SOURCES
  3. 03

    Checklists before risk

    An ownership confirmation comes first. Then ordered steps, model checks, and a progress trail you can review later.

    GATES
  4. 04

    A small, fixed command set

    Ten ADB and Fastboot actions, resolved inside the main process. No arbitrary shell. Restarts require an explicit confirmation.

  5. 05

  6. 06

03

Three steps

From cable to a record.

No accounts, no drivers bundled, no mystery downloads. Install, connect, and follow the bench.

  1. 01

    Install

    Install the bench

    Run the Windows installer. It is unsigned, so SmartScreen may ask you to confirm — the download section explains why, and how to build from source.

  2. 02

    Connect

    Connect with permission

    Use a data cable, enable USB debugging on a phone you own, and authorize the computer. DroidCrate scans the USB bus locally — never in the cloud.

  3. 03

    Work

    Follow the paper trail

    Identify the mode, read device facts, open a checklist, and keep the history entry. Stop when the next step is outside the bench.

ADB reads are safe to repeat. Anything that restarts or changes state is gated.

04

Policy, not a toggle

The line we don't cross.

A screen-lock bypass is not a feature. DroidCrate refuses those tasks in the command table, in the interface, and on this page.

Every action is resolved from a fixed table in the main process. The window cannot invent a command.

  • Read-only first: device list, properties, battery, storage, Fastboot variables.
  • Reboots require an ownership confirmation and an explicit second click.
  • Flashing, unlocking, erasing, sideloading, and arbitrary shell stay out of the table.

Screen locks, FRP, accounts, and ownership protection are refused permanently. There is no hidden mode.

07

Questions, answered

The honest version, limits included.

If the answer is not here, open an issue on GitHub. Safety questions get priority.

Open an issue
Does DroidCrate bypass screen locks or FRP?
No. It never has and never will. There is no hidden bypass, no unlock service, and no account-recovery path. The app refuses those tasks in code and on this page.
Is it really free?
Yes. DroidCrate is MIT-licensed, with no account, subscription, or ads. The full source is on GitHub, and the installer is built from it.
Does it bundle Odin, QFIL, or SP Flash Tool?
No. Those tools have no official public download we can redistribute. DroidCrate links their official support pages and marks them support-only. No mirrors, repacks, or bundled firmware.
Can it flash firmware?
No. It can reboot to bootloader or recovery and read Fastboot variables. Flashing, unlocking, erasing, and sideloading stay outside the allow-list.
Which phones work?
Any Android phone that exposes standard USB modes. The device database covers common vendors and is editable; vendor tools and firmware vary by model and region.
What can the ADB console do?
Ten fixed actions: list devices, read properties, battery and storage, restart to system, bootloader, or recovery, and two Fastboot reads. It cannot send arbitrary shell commands.
Does it need an internet connection?
Not for daily use. Lessons, checklists, history, and the tool index are local. Vendor pages open in your browser; content updates are manual downloads with SHA-256 verification.
Where does my data live?
In %APPDATA%\droidcrate on this PC: a SQLite database plus content files. There is no telemetry and no cloud account. History can be exported as CSV.
Why does Windows warn me?
The installer is unsigned, so SmartScreen cannot verify the publisher. Choose More info → Run anyway, or build from source. Signing needs a paid certificate the project does not have.
Is it a replacement for a repair shop?
No. It is a careful bench for phones you own or are authorized to service. A hard brick, a data-recovery job, or a warranty repair still belongs with a professional.
