What stays true

Quiet software. Loud craft.

No dashboards to feed, no accounts to create, no telemetry to justify. Just a small set of rules we keep on every release.

Open source, MIT

Every line is on GitHub. Read it, build it, or send a fix. No private build with extra features.

Local-first

Queues, history and settings stay on your PC. No account, no cloud sync, no analytics.

Verifiable downloads

Every release publishes the installer size and SHA-256, so you can check exactly what you run.

Small, deliberate tools

No bundled toolbars, no upsells, no second app to install. Each tool does one job, completely.

From link to app

Three steps. No detours.

Pick a tool

Majra for downloads, DroidCrate for Android. Both install like any Windows app — no account, no launcher.

Read the page

Features, honest limits, screenshots and the exact SHA-256 are on the app page before you download.

Verify and run

Hash the installer, run it, and keep everything local. Updates are yours to start, never pushed in the background.
